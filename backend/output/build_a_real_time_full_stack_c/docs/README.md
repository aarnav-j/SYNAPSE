# Build a Real-Time Full-Stack Chat Application
## Description
This project is a real-time full-stack chat application that allows multiple users to join a common chat room and exchange messages instantly. The application features a modern responsive chat UI and supports multiple clients simultaneously. It is built using Node.js, Express, Socket.IO, and vanilla HTML/CSS/JavaScript.

## Tech Stack
* Node.js
* Express
* Socket.IO
* HTML
* CSS
* JavaScript

## Getting Started
- Prerequisites: Node.js version 16 or higher
- Installation steps: Run `npm install` in the backend directory to install dependencies
- To run the application, navigate to the backend directory and run `node server.js`
- The frontend will be served automatically at [http://localhost:3000](http://localhost:3000)

## API Endpoints
There are no traditional API endpoints in this project, as it uses Socket.IO for real-time communication. However, the following events are emitted and listened for:
* `connection`: A new client connects to the server
* `disconnect`: A client disconnects from the server
* `join`: A user joins the chat room
* `leave`: A user leaves the chat room
* `message`: A user sends a message to the chat room

## Features
* Real-time messaging
* Multiple client support
* Modern responsive chat UI
* Automatic scrolling to latest message
* Timestamps beside messages
* Join/leave system notifications
* Differentiation between own messages and other users' messages
