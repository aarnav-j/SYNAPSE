# **Make a Todo App in Which We Can**
## Description
This project is a Todo application that allows users to create, read, update, and delete todo items. The application is built using a full-stack approach, with a backend API and a frontend interface. It provides a simple and intuitive way to manage todo lists.

## Tech Stack
* Node.js
* Express.js
* SQLite
* HTML5
* CSS
* JavaScript

## Getting Started
### Prerequisites
* Node.js (version 16 or higher)
* npm (version 8 or higher)
### Installation steps
1. Clone the repository
2. Run `npm install` to install dependencies
### Running the Backend
1. Navigate to the project root directory
2. Run `node server.js` to start the server
### Running the Frontend
Note: This project uses a simple frontend setup. To run the frontend, open the `index.html` file in a web browser.

## API Endpoints
* **GET /todos**: Retrieves a list of all todo items
* **POST /todos**: Creates a new todo item
* **GET /todos/:id**: Retrieves a single todo item by ID
* **PUT /todos/:id**: Updates a single todo item by ID
* **DELETE /todos/:id**: Deletes a single todo item by ID

## Features
* Create new todo items
* Read existing todo items
* Update existing todo items
* Delete existing todo items
* Input validation for todo items
