# **Build A Simple Timer App**
## Description
This project is a simple timer application that provides a basic layout with navigation, main content, and footer sections. It allows users to set a timer and receive notifications when the time is up. The application is built with a modern design and responsive layout for adaptability.

## Tech Stack
* HTML
* CSS
* JavaScript
* Node.js

## Getting Started
### Prerequisites
* Node.js (version 16 or higher)
### Installation steps
1. Run `npm install` to install dependencies.
2. Create a new file named `server.js` in the root directory to set up the backend server.
3. Run `node server.js` to start the backend server.
### Running the Frontend
To run the frontend, navigate to the `frontend` directory and run a development server using a tool like Vite or a similar setup. This will allow you to view the application in a web browser and test its functionality.

## API Endpoints
* **GET /**: Returns the index.html file for the timer application.
* **POST /timer**: Starts a new timer with the specified duration.
* **GET /timer**: Returns the current state of the timer.
